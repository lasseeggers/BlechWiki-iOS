## Kurz gesagt

Die App hat kein Konto, keine Werbung, keine Analyse und kein Tracking. Was du in der App einträgst, bleibt auf deinem Gerät.

## Was auf dem Gerät gespeichert wird

- das Liederverzeichnis von blechwiki.de, damit die Suche ohne Internet funktioniert
- dein Inventar (welche Bücher im Notenschrank stehen) und die gewählte Landeskirche
- zuletzt geladene Suchergebnisse
- geladene Titelbilder, damit sie nicht jedes Mal neu geladen werden

Diese Daten verlassen das Gerät nicht. Auf iPhone, iPad und Android werden sie mit der App gelöscht. Auf dem Mac bleiben sie nach dem Löschen der App in den Ordnern `~/Library/Containers/blechwiki.eggers.media` und `~/Library/Group Containers/group.blechwiki.eggers.media` liegen, dort kannst du sie von Hand löschen.

## Welche Server die App anfragt

- **blechwiki.de** (Schnittstelle unter `pcportal.ddns.net`): Liederverzeichnis, Bücher, Inhaltsverzeichnisse, Suchergebnisse und die Liste geänderter Einträge. Die App schickt dabei nur, was für die Antwort nötig ist, zum Beispiel die Kennung eines Buchs oder Lieds.
- **Bildserver von blechwiki.de** (`teddymuetze.ddns.net`): die Titelbilder der Bücher. Die App schickt dabei nur den Dateinamen des Bilds.

Wie bei jeder Verbindung im Internet erhalten die Server dabei die IP-Adresse deines Geräts. Die App sendet keine Kennungen, mit denen sich dein Gerät oder deine Person wiedererkennen ließe. Für die Verarbeitung auf diesen Servern sind ihre Betreiber verantwortlich.

## Inventar teilen

„Inventar teilen“ erzeugt einen Code mit den Kennungen deiner Bücher. Die App verschickt ihn nicht selbst, sondern übergibt ihn an den Teilen-Dialog des Systems. Wohin der Code geht, entscheidest du.

Teilst du eine Nachricht mit einem solchen Code an BlechWiki, liest die App den geteilten Text nur auf dem Gerät, um den Code darin zu finden. Der Text wird weder gespeichert noch verschickt.
